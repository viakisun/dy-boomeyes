## 검증 중 수정한 결함

- 첨부 성공 메시지가 쿼리 이동 중 사라짐 → 전역 상태 메시지와 실제 목록 반영을 검사.
- 미리보기 취소 후 포커스 소실 → 선택 입력으로 복귀.
- 서류·영상 왕복에서 검색/필터/스크롤 복귀 주소가 지워짐 → 허용된 내부 상세·목록 주소를 유지.
- 같은 호기 다른 용도 카메라, 다른 호기의 알림 선택 혼합 → 호기와 용도를 함께 대조.
- 경계 세트의 부품 값/점검 알림 불일치, A4 홈·구 명칭·로그아웃 캐시 → 원천/세션 초기화 정리.
- 없는 지도 높이 토큰과 긴 마커 라벨 겹침 → 기존 지도 높이 토큰·호기 번호 라벨·간격·44/48 터치 크기. 실제 핀/라벨 중앙의 입력 대상까지 검사.
- 확대 첨부 창의 화면 넘침 → 공통 Dialog의 컨테이너 기준 최대 폭과 버튼 줄바꿈.
- 문서 이미지가 늦게 로드되며 첨부 입력이 이동 → 종이 비율의 미리보기 영역을 확보하고 안정된 원문 상태에서 과제 검사.
- PWA 서비스 워커 캐시가 HTTP503 주입을 가림 → 네트워크 오류 검사는 SW를 차단. 실제 설치/오프라인 셸·큐는 기존 회귀에서 별도 검사.
- 해제된 video의 currentSrc 문자열이 남음 → 독립 계측으로 readyState/networkState/버퍼/seekable/시간/해상도 초기화를 확인. 문자열만으로 자원 누수를 판정하지 않음.

최초 실패 JSON/trace와 수정 후 결과를 별도로 보존한다. 실패를 재실행 성공으로 덮어쓰거나 검사 기준을 낮추지 않는다.

## 재현과 시연

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm --filter @boomeyes/web preview --port 4173 --strictPort
pnpm --filter @boomeyes/pwa preview --port 4174 --strictPort
```

WEB: `http://localhost:4173/login?demo=owner`, PWA: `http://localhost:4174/a4/login`. 시작 버튼→보유 장비→마포 검색→1호기→계약/김현장→서류 원문→영상→목록 복귀. 기본 시연은 한빛중기 5대, 자료 기준 2026-07-03 10:42이다. 2026-09-11 현재 장비 정보로 표시하지 않는다.

로그아웃/새로고침은 시연 첨부와 읽음 상태를 초기화한다. 두 소유주 자료를 일반 주소의 ownerId만으로 전환하는 기능은 없다. 테스트의 B 계정은 별도 브라우저 세션을 준비한다.

## 판정과 외부 단계

- 내부 검증은 `pnpm verify`, `pnpm build`, 전체 E2E, 112 기본 캡처와 14개 전체 내용, 예외 캡처, owner:check, 성능, PDF/독립 리뷰의 실제 결과로 판정한다.
- 자동 확대 증거는 CSS zoom=2와 가로 회전이다. 브라우저 메뉴 확대를 자동 실행한 것으로 기록하지 않는다.
- 수신 상태는 시연 값의 표시/집계/시각을 검사한다. 실제 수신 임계 계산·실장비 인입·실인증·영상 보존·영구 저장의 운영 검증을 뜻하지 않는다.
- 잘못된 `%` 원문 URL은 기존 SvelteKit 라우터 단계의 플랫폼 한계다. 정상 URL 인코딩된 비존재 호기/자료의 안전한 안내를 검증했다.
- 독립 구현 검토, 사람 PR 리뷰, 해당 PR head의 CI, 실제 고객 과제와 공개 승인은 별도 상태다. 개발 브랜치를 main에 병합하거나 고객에게 자료를 전송하지 않는다.
- 현재 통합 브랜치의 선행 커밋은 domain/SSOT 통합에 의존한다. 독립 PR로 나눌 때 원천/데이터→공통 패턴→화면별 활성화 순서와 PR당 제품 화면 3개 제한을 지킨다. 파일 개수로 실제 영향 화면을 대신 세지 않는다.

## 공개 후보와 복구

공개 전 사용자가 검토한 소스 SHA와 WEB/PWA 빌드 디렉터리를 고정한다. 외부 URL에서 시작·직접 상세 새로고침·PDF/MP4 응답·PWA 업데이트/오프라인을 확인하고 승인된 주소로만 공개한다. 실패 시 이전에 검증된 두 앱의 정적 빌드를 함께 복원하고 PWA 캐시 버전을 확인한다. 로컬 preview 주소는 외부 고객 접속 주소가 아니다.
