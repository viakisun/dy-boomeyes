# 앱 지도

## 역할과 앱

역할은 7, 앱은 8이다. **한 역할이 웹과 폰을 둘 다 갖는 경우가 있어** 앱 이름은 역할이 아니라
`<대상>-<플랫폼>` 으로 짓는다. 아카이브 서피스 코드를 함께 적어 예전 자료와 이어 둔다.

| 앱 | 아카이브 | 역할 | 조직 | 상태 |
|---|---|---|---|---|
| `owner-web` | B1 | `owner` 사업주 | 사업주(장비 소유주) | **있음** |
| `hq-web` | B2 | `hq-safety` 본사 안전관리자 | 건설사 본사 | **있음** |
| `owner-pwa` | A4 | `owner` | 사업주 | 없음 |
| `hq-pwa` | A3 | `hq-safety` | 건설사 본사 | 없음 |
| `site-web` | B3 | `site-safety` 현장 안전관리자 | 건설사 현장 | 없음 |
| `site-pwa` | A1 | `site-safety` | 건설사 현장 | 없음 |
| `driver-pwa` | A2 | `driver` 운전자 | 사업주 소속 | 없음 |
| `admin-web` | B4 | `ops-admin` CPB 운영 관리자 | 제조사(DY) | 없음 |

`control`(관제)과 `maintenance`(정비)는 B1을 `owner` 와 함께 쓴다 — 범위만 다르다.

**「건설사」는 역할이 아니라 조직이다.** 건설사 쪽 역할은 `site-safety` 와 `hq-safety` 둘이고,
둘은 하는 일이 다르다 — 본사는 열람, 현장은 업무 처리.

---

## `owner-web` — 사업주 운영 WEB

전국에 흩어진 보유 장비를 한 화면에서 보고, 현장에서 온 요청에 호기를 배정한다.

| 화면 | 무엇 |
|---|---|
| 운영 현황 | 전국 지도(현장 13) → 현장 지도(호기) → 호기 상세 + 카메라 6분할 · 전체 화면 |
| 보유 장비 | 120대 표 — 검색·상태/현장/계약 필터·정렬·현장별 묶기 |
| 요청 | 현장 요청 목록 → 후보 호기(서버가 고름) → 배정 확정 |
| 알림 | 고장·지연·점검·AI·계약 종료 임박 |

**일부러 안 하는 것** — 배정 이후 전이(운송·설치·가동·종료) · 운전자 배치 · 임대 계약 ·
서류 실물(링크는 자리만) · 이벤트 복기 · 쇼케이스.

## `hq-web` — 본사 안전관리자 WEB

자사 전 현장의 안전 현황을 파악한다. **직접 처리하지 않는다** — 읽기 전용이다.

| 화면 | 무엇 |
|---|---|
| 우리 현장 | 자사 현장 목록 + 지도 |
| 현장 상세 | 호기 목록 + 현장 지도 |
| 호기 | 호기 상세 + 카메라 6분할 · 전체 화면 |
| 알림 | 자사 현장 것만 |

로그인이 생기기 전까지 회사는 주소로 고른다 — `/hq-web.html?company=대양건설`.

**빠진 것** — 아카이브 B2는 화면이 셋인데 둘만 만들었다.

- **확인 요청**(본사 → 현장) — 본사 안전관리자가 현장 업무를 직접 처리하지 않고 확인을
  요구하는 액션. **이것이 이 역할을 그냥 읽기 전용 뷰어와 구별짓는 유일한 동작이다.**
- **보고 모드**(B2-04)

둘 다 시안이 없어 만들지 않았다.

## 다음은

**안전관리자.** 다만 이 역할은 서피스가 둘이라 **어느 쪽인지 먼저 정해야 한다.**

- `site-pwa`(A1) — 현장에서 폰으로. 업무함 처리·장비 영상 확인·기록
- `site-web`(B3) — 현장 사무실 PC로. 현장 콘솔·업무·서류·기록·부품 현황

## 화면은 시안이 먼저다

시안이 있는 것은 **운영 현황 하나뿐**이다(`design/운영 현황 목업.html`). `hq-web` 은 그것을
줄여 만들었고, 그래서 B2 고유 동작인 확인 요청이 없다.

이번 재시작의 원인은 **시안 없이 번역해서 라운드마다 어긋난 것**이었다. 상상으로 화면을
만들면 같은 일이 반복된다. 새 앱은 시안을 먼저 만들고 그것을 채용한다.

62화면 전체 지도(무엇을 만들기로 했었는지)는 아카이브에 있다:

```sh
git show archive/svelte-2026-09-14:ssot/screens.yaml
git show archive/svelte-2026-09-14:ssot/roles.yaml
```
