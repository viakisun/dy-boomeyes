# owner-experience — 소유주 데모

## 목적과 근거
V5(20260908) 관제기능의 소유주 장비 조회 흐름. 승인된 [구현 계획](../../docs/plans/owner-demo-implementation-plan.md)을 실행한다. 실제 고객 승인·실인증·장비 연동은 이번 내부 데모 검증과 구분한다.

## 화면
화면·메뉴·고객 질문·원문 셀은 ssot/screens.yaml의 owner_demo에서 생성한다. 진입과 업무 화면을 WEB/PWA 쌍으로 제공하고(목적 수는 `owner_demo`가 정한다) **좌측 메뉴는 운영 현황 · 보유 장비 · 계약 셋**이다(시안 «결정 2026-09-12»). 이상·점검과 장비 서류는 메뉴에서 내려와 종 알림 패널과 호기 화면의 접기로 들어가지만 화면 자체는 남는다. 계약·운전자의 수용 기준은 [owner-contracts](../owner-contracts/spec.md)·[owner-drivers](../owner-drivers/spec.md)가 갖는다. scene 모드는 기존 시연 명세와 데이터를 우선하며 일반 owner 세션에서 새 경험을 제공한다.

## 수용 기준
- **AC-1** Given 승인된 소유주 데모 세트 When 소유주 데모 URL → 로그인 폼(아이디·비밀번호, 데모 계정은 "데모 계정으로 로그인"이 채움 · 잘못된 계정은 오류 한 줄) → owner 세션·ownerId·운영 현황·4메뉴. 역할 재선택 없음, 화면에 계정 ID 표시 없음 Then AC-O01 진입의 결과를 VT-02·03로 확인한다. [FR-001, FR-024]
- **AC-2** Given 승인된 소유주 데모 세트 When 정상/보관/이상 장비가 있는 세트 → 호기·현장 검색/필터 → 해당 소유주 전체 장비 중 맞는 결과와 결과 수 Then AC-O02 검색의 결과를 VT-01·03로 확인한다. [FR-025]
- **AC-3** Given 승인된 소유주 데모 세트 When 필터한 목록 → 호기 선택 → 같은 호기·현장·계약 기간·담당자 확인 → 뒤로가면 필터/위치 유지 Then AC-O03 상세·복귀의 결과를 VT-03·05로 확인한다. [FR-019, FR-025]
- **AC-4** Given 승인된 소유주 데모 세트 When 배치 상태가 알려진/미확인 장비 → 현황 → 전체=투입+보관+배치 미확인. 고장·점검 중복으로 총량이 늘지 않음 Then AC-O04 집계의 결과를 VT-01·03로 확인한다. [FR-025, FR-039]
- **AC-5** Given 승인된 소유주 데모 세트 When 현재/미수신/미연동/미장착 세트 → 상태 확인 → 각각 구분, 과거 값에 마지막 시각. 계약 없음도 ‘없음/미등록’ 원인에 맞게 표시 Then AC-O05 정보 시각의 결과를 VT-01·03·04로 확인한다. [FR-002, FR-040, FR-043]
- **AC-6** Given 승인된 소유주 데모 세트 When 특정 호기의 알림 선택 → 상세·상태 이동 → 대상 일치, 다른 서류 승인 없음. 읽음은 고장 해소와 별개 Then AC-O06 알림의 결과를 VT-01·03로 확인한다. [FR-006, FR-007]
- **AC-7** Given 승인된 소유주 데모 세트 When 전체 영향 장비가 표시 한도 초과 → 현황 → 전체/현재 표시 수·전체 보기. 동일 호기의 복수 알림은 집계 기준대로 구분 Then AC-O07 일부 목록의 결과를 VT-01·03로 확인한다. [FR-006, FR-007, FR-025]
- **AC-8** Given 승인된 소유주 데모 세트 When 채널이 제공된 호기 → 영상 → 타설/설치/작업 용도·선택 호기·시연 표시. 안전 감지 상시 실시간·원격 제어 버튼 없음 Then AC-O08 영상 용도의 결과를 VT-03·04·07로 확인한다. [FR-004, FR-005]
- **AC-9** Given 승인된 소유주 데모 세트 When 실시간 예시/스냅샷/저장/미확보 → 전환 → 상태·해당 시각이 일치하고 저장 길이=실제 클립 길이. 닫으면 재생 자원 정리 Then AC-O09 재생 상태의 결과를 VT-03·04·07로 확인한다. [FR-004, FR-005]
- **AC-10** Given 승인된 소유주 데모 세트 When 호기의 제작증/검사 성적서 → 파일 열기 → 정확한 문서 본문·호기 식별. 닫으면 선택 유지 Then AC-O10 원문의 결과를 VT-03·04·07로 확인한다. [FR-016]
- **AC-11** Given 승인된 소유주 데모 세트 When 허용 샘플 파일 → 선택/미리보기/확정 → 같은 호기의 세션 목록 반영. 실패·취소는 성공 처리하지 않음 Then AC-O11 첨부의 결과를 VT-01·03·04로 확인한다. [FR-016]
- **AC-12** Given 승인된 소유주 데모 세트 When 소유주 A/B 자료 → A로 목록·상세·직접 URL/API 조회 → B의 장비·문서·카메라·알림·계약·연락처가 노출되지 않음 Then AC-O12 스코프의 결과를 VT-01·02로 확인한다. [FR-001, FR-002, FR-004, FR-005, FR-006, FR-007, FR-016, FR-019, FR-024, FR-025, FR-039, FR-040, FR-043]
- **AC-13** Given 승인된 소유주 데모 세트 When WEB/PWA 각 기준 폭 → 탐색/상세/뷰어 → 본문 가로 넘침·액션 잘림·상세 소실 없음. 확대/회전에서도 닫기·복귀 가능 Then AC-O13 반응형의 결과를 VT-05·06로 확인한다. [FR-003, FR-016, FR-024]
- **AC-14** Given 승인된 소유주 데모 세트 When 빈/로딩/조회 실패/오프라인 → 해당 페이지 → 원인과 가능한 행동. 미수신·통신 중단을 정상으로 표시하지 않음 Then AC-O14 예외의 결과를 VT-04·06로 확인한다. [FR-002, FR-003, FR-004, FR-005, FR-016, FR-040, FR-043]
- **AC-15** Given 승인된 소유주 데모 세트 When 필터·호기·시연 시각이 있는 상태 → 탭/페이지/뒤로/새로고침 → 약속한 값 유지. 재설정되는 첨부 데이터는 시연 안내와 일치 Then AC-O15 맥락의 결과를 VT-03로 확인한다. [FR-001, FR-003, FR-006, FR-007, FR-016, FR-019, FR-039]
- **AC-16** Given 승인된 소유주 데모 세트 When 키보드·터치·라이트/다크 → 주요 과제 → 이름·포커스·대비·터치 기준 충족, axe serious/critical 0 Then AC-O16 접근성의 결과를 VT-06로 확인한다. [FR-024]
- **AC-17** Given 승인된 소유주 데모 세트 When 기존 7역할·기존 데모 장면 → 기존 업무 → 권한·화면·처리 흐름 유지. 의도한 변경은 spec과 기대값을 함께 갱신 Then AC-O17 역할 회귀의 결과를 VT-08로 확인한다. [FR-001, FR-024]
- **AC-18** Given 승인된 소유주 데모 세트 When 검증된 동일 빌드 → 소유주 데모 문서 생성 → 화면/호기/시각/역할/원문 근거 일치, 역할 선택·정적 시안이 완성 화면으로 섞이지 않음 Then AC-O18 문서 일치의 결과를 VT-09·11로 확인한다. [FR-003, FR-016, FR-024]

## 상태와 비범위
owner / empty / error / boundaries / large 상태는 capture에서만 적용한다. live의 상태 쿼리는 데이터를 바꾸지 않는다. 시연 첨부는 앱 메모리에만 유지하며 새로고침·로그아웃 시 초기화한다. 2026-09-12 사용자 결정으로 **계약(요청 접수·호기 배정·기간 확정)과 운전자(배치·서류)는 범위에 들어왔다**(DISC-052 · 시안 «확정 2026-09-12» · ADR-014). 오프라인 업로드 큐, 정비 완료 처리, 실영상 저장 정책은 그대로 추가하지 않는다. 미결은 DISC-052·DISC-059 및 기존 원장에 유지한다.
