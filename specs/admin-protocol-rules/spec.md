# admin-protocol-rules — 프로토콜 관리 · 알림 기준

## 목적 · 역할
관리자(`ops-admin`)가 장비 프로토콜 정의(ENT-11)를 업로드·검증·샘플 테스트하고, 알림 8종의 등급·수신 역할·임계값과 고장코드 표를 관리한다. 데모 D4 장면 8(확장성: 프로토콜 YAML 업로드 → 오류 샘플 파싱 테스트(필드 누락·타입 오류) → 알림 발생 확인)의 화면이다. 검수 ACC-011·ACC-109가 이 화면으로 시연된다.

## 화면
| 코드 | 이름 | 라우트 | 상태 픽스처 |
|---|---|---|---|
| B4-02 | 프로토콜 관리 | `/b4/protocols` | `proto` |
| B4-05 | 알림 기준 | `/b4/rules` | `rules` |

## 수용 기준
- **AC-1** Given 시드 프로토콜(cpb.v0.1 운영 · 테스트 버전 1) When B4-02 로드 Then 버전·운영/테스트 구분·필드 수·마지막 수신 시각이 목록에 보이고 운영 버전이 표시된다 [FR-020]
- **AC-2** Given YAML 정의 파일 When 업로드 Then 스키마 검증 결과(필드·타입·단위 — 숫자 필드는 단위 필수)가 표시되고, 오류 시 경로(행)와 사유가 나열되며 저장되지 않는다 [FR-020]
- **AC-3** Given 샘플 JSON 4종(정상 · 이상 값 · 필드 누락 · 타입 오류) When 파싱 테스트 Then 샘플별 정상/오류와 오류 항목(경로·사유)이 표시되고, 오류 샘플에서도 파싱 가능한 값에서 발생할 알림(유형·등급)을 미리 보여준다 — 타입·허용값이 틀린 값은 알림으로 오인하지 않는다 (D4 장면 8: 오류 샘플 파싱 테스트 → 알림 발생 확인) [FR-020, FR-011]
- **AC-4** Given 알림 기준 목록 When B4-05 로드 Then 알림 8종별 등급·수신 역할·임계값(수송관·필터 도달률 caution/danger)이 표에 보이고 편집·저장할 수 있다 [FR-011, FR-007]
- **AC-5** Given 고장코드 표 When B4-05 고장코드 탭 Then E-021 등 코드·설명·원격 진단 가이드를 열람·편집할 수 있다 [FR-006]
- **AC-6** Given 시나리오별 알림 등급(정상 타설 무알림 · 호스 주변 인원 접근 즉시 · 배관 이상 긴급 · 영상 장애) When B4-05 Then 2단계 항목으로 표시되고 전도·무동작은 "현장 검증 후"로 잠겨 있다(DISC-042) [FR-036]
- **AC-7** Given 규칙·프로토콜 저장 When 저장 Then 변경 이력(누가·언제·무엇)이 남고 목록에 최신 갱신 시각이 표시된다 [FR-020, FR-011]

## 상태 픽스처
`screens.yaml` B4-02 `proto` · B4-05 `rules`. 픽스처 ID: cpb.v0.1 · 샘플 4종(`interfaces.protocol.sample` 기반 — 정상 · 이상 값 · 필드 누락+단선 · 타입 오류+고장코드) · E-021 · ops01.
