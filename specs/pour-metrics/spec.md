# pour-metrics — 타설량 추세 · 가동률 · 누적 (FR-039 · DISC-055 기준안)

## 목적 · 역할
수송관 진동 센서 기반 타설량(FR-039)을 서버 집계 시간 버킷(ADR-013)으로 받아 관제·현장·운전자·부품 화면에 보인다. 소유주(B1)는 호기별 추세와 가동률로 임대 장비의 실제 사용을 보고, 현장 안전관리자(A1)는 부품 탭에서 24시간 추세와 누적을, 운전자(A2)는 오늘 타설량과 가동률만 본다. 부품 대장(B4-07)의 누적 타설 진행 막대는 임의 분모(최대 타설 부품) 대신 참고 기준(`Part.guideM3`)을 쓴다 — 단독 폐기 기준이 아니다(FR-032 · DISC-038). 산출 방식·센서 사양·표시 범위는 DISC-055로 열려 있어 화면은 `data-ref="DISC-055"`와 산출 근거(`PourSeries.basis`)를 함께 보인다.

## 수용 기준
- **AC-1** Given capture 고정 시각(KST 10:42)의 시드 When B1-02 인스펙터에서 CPB-003(기본 선택) Then "타설량 12h" 차트가 최근 12버킷(KST 23시~10시)을 막대 12개 + 보이는 캡션(합계 31 m³ · 최대 · 가동률 82%) + sr-only 표로 보이고, 누적 3,910 m³와 산출 근거(D125 0.0123 m² · L 1.5 m)가 `data-ref="DISC-055"`로 붙는다 [FR-039, FR-002]
- **AC-2** Given 같은 시드 When A1-05 부품 탭(`?tab=parts`) Then 마모·교체 부품 도달률 아래 "타설량" 블록에 누적 3,910 m³ · 24시간 165 m³ · 오늘 31 m³ · 가동률 82%와 24버킷 차트("타설량 24h")가 보인다 [FR-039, FR-032]
- **AC-3** Given 운전자 driver03(A2-04 `mydev`) When 내 장비 Then 텔레메트리 아래 "타설량" 블록에 오늘 31 m³와 가동률 82%(선형 진행 막대)만 보이고 차트는 없다 [FR-039, FR-007]
- **AC-4** Given B4-07 부품 선택 When 인스펙터 누적 타설 진행 막대 Then 분모가 참고 기준 `guideM3`(3,000 m³)이고 힌트에 "참고 기준 · 단독 폐기 기준 아님"이 보인다; 참고 기준이 없는 부품은 종전 분모(최대 타설 부품)로 남는다 [FR-032, FR-039]
- **AC-5** Given 정비 중 CPB-005(24버킷 전부 0 · SITE-002) When B1-02 인스펙터에서 정비 마커를 선택 Then "타설량 12h" 합계 0 m³ · 가동률 0%로 보이고 "미연동"이 아니다(캡처 세션 safety01은 SITE-001뿐이라 A1-05로는 열 수 없다 — AC-15); `Device.pour`가 없는 장비만 "타설량 미연동"이다. 차트 라벨은 호출부가 `fmtHour`(Asia/Seoul)로 만들며 컴포넌트는 시각을 모른다 — 시각 회귀는 `packages/mock/src/pour.test.ts`의 첫/마지막 `at` 리터럴이 픽셀 diff보다 먼저 잡는다 [FR-039, FR-034]

## 상태 픽스처
- `A1-05:pour` — 데이터는 `dev`와 같고 `?tab=parts`(capture `STATE_QUERY`)로 부품 탭을 연다.
- 나머지는 기존 픽스처(`dash` · `mydev` · `default`) — 시드에 `pour`가 상태별 리터럴로 들어 있다(PR #59).

## 비범위
- 실시간 갱신(`device.updated`) — 캡처 결정성 우선, W3 실연동에서.
- 현장별·전국 집계 차트, 기간 선택, 교체 시기 예측(부품별 소모 속도) — DISC-055 "관제 화면 표시 범위" 확정 후.
- 수송관 교체 시 누적 리셋 이벤트(DISC-055 ask).
