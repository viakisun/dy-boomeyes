# sites-assets-leases — 현장·장비·프로파일 마스터 · 사용자·권한 · 임대 계약 · 본사 지도 · 현장 정보 · 신청

## 목적 · 역할
운영사 관리자가 현장·호기·현장 프로파일·사용자를 관리하고(B4-03·B4-04), 관제가 임대 계약의 만료 임박(D-27)과 재배치를 다루며(B1-06, 데모 장면 9), 본사는 자사 현장을 지도로 열람하고(B2-02) 현장 정보를 앱에서 본다(A3-03). 현장·운전자 앱의 메뉴(A1-07·A2-06)는 현장 기본정보 열람과 신청 폼(현장 개설·장비 요청, FR-017 → B1-03 수신함)이다. 상태기계 `request`(ENT-20) · `lease`(ENT-10).

## 수용 기준
- **AC-1** Given `ops01` When 장비·현장·프로파일(B4-03) Then 탭 3(장비 · 현장 · 프로파일)에서 현장 등록(현장명·주소·기간·담당 안전관리자)과 호기(1~120) 배정이 되고, 프로파일 탭에서 프리셋(P-LITE · P-SD · P-NVR)을 바꾸면 B1-02 카메라 월과 A1-04 타일의 채널 수가 즉시 그 현장 프로파일을 따른다 — 8축은 표시만, 축 편집은 비활성("W4 · FR-029") [FR-018, FR-029]
- **AC-2** Given `ops01` When 사용자·권한(B4-04) Then 7역할 × 데모 계정 7의 역할·현장 범위·상태가 표에 보이고, 역할 변경 시 라우트 가드(`canAccess`)가 즉시 반영된다 — 운영사는 안전관리자 권한을 부여할 수 없다(entities.rules) [FR-021, FR-024]
- **AC-3** Given LS-001(CPB-001 · SITE-001 · 만료 D-27) When 임대 계약(B1-06) 로드 Then 만료 임박 계약이 최상단에 D-n과 함께 보이고 "재배치 계획"을 입력하면 `lease` 상태기계 `expiring → relocated`로 전이되어 이력과 대상 현장이 남는다 [FR-019, FR-024]
- **AC-4** Given `hq01`(SITE-001·002) When 본사 지도(B2-02) Then 자사 현장 2의 장비 마커(상태색)와 현장 카드가 보이고 마커 선택은 B2-03으로, "보고 모드"는 B2-04로 이동하며 처리 액션은 없다 [FR-022, FR-003, FR-024]
- **AC-5** Given `safety01` When 메뉴(A1-07) Then 현장 기본정보(현장명·주소·기간·프로파일)와 "현장 개설 신청" 시트(`apply`)가 있고, 제출하면 `request`(ENT-20) `submitted → review`로 수신함(B1-03)에 RQ가 나타난다 [FR-017, FR-018]
- **AC-6** Given `driver03` When 메뉴(A2-06) Then 배정 현장 기본정보·동의 요약(ENT-15)·앱 정보가 보이고 편집 액션은 없다 [FR-018, FR-031]
- **AC-7** Given `hq01` When 현장 상세(A3-03) `site` · `normal` Then 현장 요약(장비 수·이상·업무·완비율)과 "확인 요청" 액션(DISC-015)만 있고 처리 버튼은 없다; `normal`(대전 B)은 이상 0으로 렌더된다 [FR-022]
