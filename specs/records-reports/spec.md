# records-reports — 현장 기록 · 본사 기록 · 보고 모드

## 목적 · 역할
업무·점검·출근·서류·규칙 변경의 이력(ENT-09, append-only)을 현장 안전관리자(A1-06)와 본사(A3-06)가 열람하고, 본사가 경영 보고 모드(B2-04, 열람 전용)로 기간 요약을 본다. ops "주간·월간 운영 리포트 열람" · 장면 5(완료·증빙 → 기록).

|---|---|---|---|
| A1-06 | 기록 | `/a1/records` | `rec` |
| A3-06 | 기록(본사) | `/a3/records` | `rec` |

## 수용 기준
- **AC-1** Given `safety01`·SITE-001 When 기록(A1-06) 로드 Then 업무 이력(C-101~105 history)·점검 제출·출근·서류 이력이 시각 역순으로 한 타임라인에 보이고 유형 칩(업무 · 점검 · 출근 · 서류)으로 걸러지며 수정·삭제 액션은 없다(append-only, NFR-012) [FR-012]
- **AC-2** Given C-105를 A1-08에서 완료 처리 When 기록(A1-06)으로 이동 Then 완료 확인 행(행위자·조치 내용)이 최상단에 즉시 보인다 [FR-012, FR-008]
- **AC-3** Given `hq01`(SITE-001·002) When 기록(A3-06) Then 두 현장의 기록이 현장 칩으로 구분되어 보이고 처리 액션은 없다 [FR-022, FR-012]
- **AC-4** Given `hq01` When 보고 모드(B2-04) Then 현장별 요약(장비 수 · 이상 · 업무 처리율 · 점검 제출률 · 서류 완비율 · 에스컬레이션)이 기간 7일/30일(DemoClock 기준)로 보이고(서류 완비율은 현재 시점 지표 — 기간 무관), ESC 또는 화면 클릭으로 B2-02로 돌아가며 PDF 내보내기는 비활성("API-014 2단계")이다 [FR-023, FR-022, FR-024]

## 상태 픽스처
`A1-06:rec` · `A3-06:rec` · `B2-04:report`(7일). 데이터는 시드 이력(케이스 history · 규칙 이력)에서 병합.

## 비범위
PDF 내보내기·기간 지정 저장(API-014, 2단계) · B3-05 현장 기록(W4) · 실 집계 서버.
