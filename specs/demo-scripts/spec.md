# demo-scripts — 시연 장면 재생(리플레이 에이전트)

## 목적 · 역할
`ssot/scenarios.yaml demo[]`의 장면 1~8을 mock 위에서 **같은 순서·같은 데이터로 재현**한다(`docs/DEMO.md` §5, PLAN W1 Exit "장면 1~8이 프리뷰에서 mock으로 걸어짐"). 진행자는 `?scene=N`으로 장면에 진입하고, 셸의 장면 바에서 이전/다음 장면·"1시간 경과"를 조작한다. 실 인입(W3)이 붙은 뒤에도 통신 장애 시 폴백으로 유지한다.

역할: 장면별 계정(`demo[].fixture.account`) — control01(1·4·6) · driver03(2·7) · safety01(3·5) · hq01(6) · ops01(8).

## 수용 기준
- **AC-1** Given `/b1/dash?scene=1`(owner01 자동 세션) When 대시보드가 뜨고 타임라인이 시작되면 Then 6초 안에 "CPB-003 380V 전압 이상(E-021)" 긴급 알림이 피드 최상단·토스트로 도착하고, CPB-003이 이상 장비 표 최상단·마커 fault로 표시된다 [FR-011, FR-002, FR-003]
- **AC-2** Given `/a2/today?scene=2`(driver03) When E-021 알림을 열어 대응 안내를 확인하고 반경 안에서 출근 체크인한 뒤 A2-03에서 5항목을 제출하면 Then 오늘 화면이 근무 중·점검 완료 배너를 보인다 [FR-011, FR-013, FR-014]
- **AC-3** Given `/a1/inbox?scene=3`(safety01) When C-105를 접수하고 A1-04에서 CPB-003 2채널(라이브·스냅샷)을 확인하고 A1-05 저장 영상 목록(서버·SD)을 열고 정비 담당을 호출하면 Then C-105 이력에 접수·정비 호출이 남는다 [FR-008, FR-004, FR-005, FR-006]
- **AC-4** Given `/b1/dash?scene=4`(owner01, C-105 접수됨) When 인스펙터에서 E-021 원격 진단(고장코드 설명·조치)을 확인하고 B1-03 `?case=C-105`에서 처리하면 Then 업무 패널이 in-progress 이력과 조치 입력을 보인다 [FR-006, FR-017, FR-011]
- **AC-5** Given `/b1/escalation?scene=6`(계정 hq01 — B1-04는 hq-safety 권한이 없어 셸이 첫 역할 control 세션으로 폴백, ADR-012 §후속 3) When 진입 시 CPB-004 방치 업무가 55분(에스컬레이션 0건)이고 장면 바의 "1시간 경과"를 누르면 Then 에스컬레이션 목록에 CPB-004가 나타나고 통보 대상에 본사(hq-safety)가 포함된다 [FR-010]
- **AC-6** Given `/b4/protocols?scene=8`(ops01) When YAML을 업로드하고 오류 샘플(필드 누락·타입 오류)을 테스트하면 Then 오류 경로가 표시되고 정상 샘플은 알림 0, 이상 값 샘플은 알림 미리보기를 보인다 [FR-020, FR-011]
- **AC-7** Given `?scene=N`(1~11)으로 진입한 뒤(앱 내 이동에서는 쿼리 없이도 장면이 유지된다) When 어떤 화면이든 렌더되면 Then 셸에 장면 바 "장면 N/11 · 제목"과 이전/다음 링크(이웃 장면의 첫 화면, 계정이 다르면 그 계정으로 자동 전환 — 그 계정에 화면 권한이 없으면 화면 첫 역할의 데모 계정)가 보이고, 현재 웨이브 밖 화면(W2 종료 시 B3-06만)은 자리 화면에 웨이브를 표시한다(모달형 A1-08은 부모 A1-03 위 시트) [FR-024]
- **AC-8** Given `/b1/dash?scene=11`(owner01) When 진입 Then CPB-003이 자동 선택되어 인스펙터에 타설량 12h 차트(가동률 82% · 누적 3,910 m³ · DISC-055 근거)와 3상 결상(S 118V)이 보이고, 장면 바가 "장면 11/11 · 쌓인 데이터"이며 이전은 장면 10, 다음은 없다 — 타임라인 발행 없음(결정성) [FR-039, FR-040, FR-024]

## 상태 픽스처
장면 = `?scene=N`(live 모드, capture 아님). 진입 후 앱 내 이동은 활성 장면(`activeScene`)으로 db·장면 바를 유지하고, `?state=`·`?capture=`·로그아웃·새로고침이 리셋한다. 장면별 db 변형은 `packages/mock/src/demo.ts` `SCENE_FIXTURES`(4: C-105 접수 · 5: 정비 호출 · 6: CPB-004 55분 방치). 기존 `?state=` 픽스처와 조합하지 않는다(장면이 우선). 캡처는 기존 `?state=`로 유지.
